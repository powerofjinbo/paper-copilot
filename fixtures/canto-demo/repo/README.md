# Fixture analysis repository

A trimmed copy of three artifacts from
[powerofjinbo/Displaced_tracks_GNN](https://github.com/powerofjinbo/Displaced_tracks_GNN) (the Canto tracker),
used only by paper-copilot's tests:

- `results/addendum_g_g1_v1_claim.json`: the preregistered claim G1 (isolated displaced gun particles).
- `results/addendum_g_g1_v1.csv`: the first 12 rows of the efficiency table behind it.
- `docs/definitions.md`: the metric and target definitions.

All results are "within this simulation (ACTS generic detector, no pileup)".
